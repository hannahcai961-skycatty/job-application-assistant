秋招投递助手

OCR 读 JD → 匹配评分 → 投递表跟踪 → 生成邮件话术

本地 Web 助手：截图识岗、砍废话评估、按真实流程记状态，再生成可人工核对的邮件正文。不做线上试用，避免 API Key 与材料暴露。

你做了什么

产品

  • 砍废话评估：匹配分数 + 可执行理由，低分建议 skip
  • 多材料分主题：简历 / 经历等按主题上传，供评估与话术引用
  • 状态与渠道贴近真实投递流程（Boss / 邮箱等）
  • 投递表链接可点、字段可编辑，评估结果可一键写入

技术

  • FastAPI + 本地 JSON 存储，数据不出本机
  • 百炼兼容 API（可配 Base URL / 模型 / Key）
  • OCR 识图链路：上传或粘贴截图 → 填入 JD
  • Prompt 外置在 templates/prompts/，便于迭代文风

代码入口

本页是分享入口；仓库是代码附件。请在本地配置后运行，勿把 Key 与真实材料推上公开仓库。
