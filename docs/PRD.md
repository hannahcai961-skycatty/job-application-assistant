# Job Application Assistant — 产品需求文档

> 版本：v0.3 | 更新：2026-09-20  
> 目标：岗位适配度评估 + 投递记录表 + 邮箱话术  
> 相对 v0.2.1：恢复邮箱话术；删除经历/简历；仪表盘改为投递总览；评估页 = OCR→分数+理由→可写入投递表

---

## 1. 产品目标

| 目标 | 说明 |
|------|------|
| **岗位评估** | 截图 → OCR → 分数 + 理由 → 可选写入投递表 |
| **投递记录表** | 类 Excel：公司、岗位、渠道、状态、投递日、面试轮次、备注（及链接/JD/匹配结果） |
| **邮箱话术** | 根据 JD 生成邮件；JD 可来自 OCR / 粘贴 / 投递表 |

### 删除

- 经历素材库（UI + API）
- 简历库（UI + API）
- Boss 招呼语、简历微调、一键流水线

### 匹配基准

设置中的「个人简介 / 能力基准」文本（替代原简历）。

---

## 2. 页面

| 页面 | 功能 |
|------|------|
| 仪表盘 | 全部投递数据总览（状态分布、最近记录、匹配分概览） |
| 岗位评估 | 截图 OCR → 评估分数+理由 → 可写入投递表 |
| 投递表 | 类 Excel 编辑七列 + 链接/JD |
| AI 工作台 | 仅邮箱话术；JD 来源：OCR / 粘贴 / 从投递表读取 |
| 设置 | API Key、个人简介基准 |

---

## 3. 核心流程

### 3.1 岗位评估

```
上传截图 → OCR（公司/岗位/链接/岗位要求）
        → 对照个人简介做匹配
        → 分数 + 理由
        → 可选：写入投递表
```

URL 抓取非本迭代硬依赖；OCR 为主路径。

### 3.2 邮箱话术

```
JD 来源三选一：OCR 截图 | 粘贴 JD | 从投递表选一行
        → 生成邮件主题 + 正文（+ 附件建议）
        → 人工复制发送
```

### 3.3 投递表最少列

公司、岗位、渠道、状态、投递日、面试轮次、备注  
（另存 url、jd_text、match_score、match_reason 供评估/话术复用）

状态暂沿用 `templates/states.yml`。

## 4. API 方向

| 动作 | 路径 |
|------|------|
| 投递 CRUD | `/api/jobs` |
| OCR | `POST /api/ingest/ocr` |
| 匹配 | `POST /api/ai/match`（JD 文本 + 个人简介） |
| 邮箱 | `POST /api/ai/email-draft` |
| 设置 | `/api/settings`（含 profile_text） |
| 删除 | experiences / resumes / tune / boss / auto-pipeline |
