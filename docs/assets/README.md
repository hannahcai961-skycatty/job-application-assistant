# 演示媒体

把录屏放到本目录后刷新展示页即可，**不必改** `docs/index.html` 结构。

## 支持的文件名（按优先级）

1. `demo.mp4` — 推荐，30–60 秒流程录屏  
2. `demo.gif` — 若无 mp4，可用 GIF 代替  

页面会先探测 `demo.mp4`，不存在再尝试 `demo.gif`；两者都没有时显示「待补录屏」。

## 建议内容

建议覆盖：截图 OCR → 匹配评分 → 写入投递表 → 生成邮件话术（可剪辑）。

## 注意

- 文件名请保持为 `demo.mp4` 或 `demo.gif`（小写）  
- 勿在录屏中露出 API Key、真实简历或隐私信息
